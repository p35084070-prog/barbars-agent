# Правила игры и ловушки (проверено на живых данных 15–16.11.2026)

## Валюты

| Валюта | Где тратится | Как добывается | Правила игрока |
|---|---|---|---|
| Золото | покупки за реальные деньги, «Поход», «Мудрец», дорогие вещи | бой, продажа ресурсов, почта | **не тратится**, кроме явно разрешённой покупки снаряжения |
| Серебро | «Магазин снаряжения» (основные цены), мелкие покупки | сдача при оплате золотом, продажа ресурсов, почта | на алтарь не тратится |
| Железо | ремонт, улучшение параметров, покупка железа на бирже | башни, подземелья | **не продаём** (решение игрока) |
| Мифрил | «Мастера», «Мудрец» | профессия «искатель мифрила», клановые задания | **не пересылаем** |

Курс в магазине: 1 золото = 100 серебра. В почте 1 зол + 63 сер приходят как
«4363 серебра» и зачисляются золотом.

## Почта

- «ЗАБРАТЬ ВСЕ ИЗ ПОЧТЫ» (`getAllFromMessages`) забирает **деньги**, но не посылки с вещами.
- Посылка с вещью: открыть `/user/mail/message/id/<id>` → кнопка «ЗАБРАТЬ ИЗ ПОЧТЫ»
  (`getLink`). После забора игра показывает панель «новый предмет» («в рюкзак»).
- Отправка: `/user/mail/send/id/<id>` → вкладка «Вещи» (`sendMessageForm:mailItemLink`)
  → источник «Рюкзак» или «Витрина» → выбор предмета → «отправить».
- Комиссия 5 % — только для денег, вещи идут без комиссии.

## Снаряжение

- Слоты: шлем, амулет, наплечник, накидка, броня, пояс, штаны, браслет/наручи,
  перчатки, перстень/кольцо, оружие, обувь — 12 штук.
- Названия вещей отличаются по наборам (Берсерк/Голиаф/Атлант/Ветерана), слот один и тот же:
  «наручи» = слот перчаток, «кираса»/«кольчуга» = броня, «бурка»/«накидка» = накидка.
- **id в каталоге магазина и id самой вещи — разные числа**: каталожный `40121857`
  (страница товара), после покупки вещь получает свой id `2093943869` (рюкзак).
  Для отправки почтой нужен **id из рюкзака** — его берёт `gear-transfer.yml` по списку
  вещей, а не по каталожным id.
- Тир виден по иконке: `bonusdarkiron` мифический, `bonusrare` редкий, `bonusepic` эпический.
  Мифические/легендарные/эпические не ломаем — это награда за дракона.
- Пометка «Лучше (+N)» = вещь сильнее надетой; такие сначала надеваем.
- **Уровень вещи важнее**: вещь 25 ур. нельзя надеть раньше 25 уровня героя
  («Ты не можешь надеть эту вещь, требуется 25 уровень. У тебя пока 12»).
  Проверяй уровень товара на его странице до покупки, иначе можно купить комплект
  «не того уровня» (например, 21–24 ур. у набора Ветерана).
- Рюкзак 20 слотов, сундук ещё 20; при полном рюкзаке **опыт героя не растёт**.

## Клан

- Вступать можно с 11 уровня (`tests/clan_join_auto.py` — вступление в клан;
  в нём зашит ник, новому герою его надо поменять на свой).
- Хранилище (`/guild/storage/0/<id>`): **ничего не вливаем**.

## Бой и прокачка

- Башня (`/game/towers`) — бесплатный бесконечный фарм: опыт, бутылочки, железо, дроп.
- Подземелья — с 10 уровня; «Поход» — с 10 уровня; в кланы пускают с 10+.
- «Мудрец» (`/trade/ironmaster`) — опыт **только за золото** (8 зол = 17 % опыта),
  поэтому ускорение прокачки бесплатно невозможно.
- «Сразиться ещё за 1 золото» и «Открыть всё за 50» — платные кнопки, не жмём.
- Усталость от башен: снимается сама за ~9–10 ч или за 5 золота (не тратим),
  поэтому при усталости герой в башни не ходит.

## Клан

- Хранилище (`/guild/storage/0/<id>`): **ничего не вливаем**.
- Алтарь: пополняет **только keis** и **только железом** (1250 → +12,5 % на ~2,5 ч).
  Серебро (87 → +25 %) и золото на алтарь не используем.
- Вклад в клан (`spend.clan_donate`) выключен у всех героев.

## Пароль и доступ к аккаунту

- **Пароль входа меняется в «Настройках»** — `https://barbars.ru/user/settings`, блок
  «Смена пароля»: поля `oldPassword`, `newPassword`, `newPassword2`, кнопка
  «Сменить пароль». После успеха игра пишет «Пароль изменен».
- **Страница «Защита аккаунта» (`/user/protection/0/1`) — другое**: это пароль защиты,
  **пароль для входа он не меняет** (проверено 16.11: после смены там вход со старым
  паролем оставался рабочим, со «новым» — нет).
- **Email задаётся там же**: в «Настройках» ссылка «Установить Email» → форма
  «Укажи Телефон или Email, которые нужны для восстановления пароля от героя».
  Пока email/телефон не задан, `/password/restore` отвечает «При регистрации не были
  указаны Email или Номер телефона. Восстановление пароля невозможно». Поэтому при
  онбординге email надо ставить сразу — иначе утёкший пароль уже не вернуть.
- **Источник истины по паролю — лог прогона регистрации**, а не текущий секрет:
  в логе `register-hero`/`register-steelblue` есть строка `пароль=<значение>`,
  в артефакте `registration-<аккаунт>-<n>` — `credentials-<аккаунт>.json`.
  Логи GitHub живут 90 дней, артефакты — 5 дней (по умолчанию).
  ```powershell
  gh run list -R p35084070-prog/barbars-agent --workflow register-steelblue.yml --limit 10
  gh run view <run_id> -R p35084070-prog/barbars-agent --log
  ```
- **Публичный репозиторий = публичные логи прогонов.** Пароль, напечатанный в логе
  регистрации, доступен всем. После смены пароля логи и артефакт удаляют:
  ```powershell
  gh api -X DELETE repos/p35084070-prog/barbars-agent/actions/runs/<run_id>/logs
  gh api -X DELETE repos/p35084070-prog/barbars-agent/actions/artifacts/<artifact_id>
  ```
  Удаление логов пароль не отменяет — помогает только новая смена пароля в игре.
- Проверять пароль локально: `python tools\check_login.py "<ник>" "<пароль>"`;
  из облака: `probe-login-secret.yml` (`-f account=<аккаунт>`).
- Для писем восстановления подходят публичные ящики без регистрации:
  guerrillamail (`https://api.guerrillamail.com/ajax.php?f=get_email_address` + `sid_token`),
  mailinator (инбокс `https://www.mailinator.com/inbox/<local>`); 1secmail — SSL-ошибка.

## Секреты и доступы

- Креды героев — только в GitHub Secrets: `BARBARS_<ГЕРОЙ>_LOGIN` / `_PASSWORD`.
- Локальных файлов кредов нет: они лежат только в секретах и в `state/<аккаунт>/credentials.json`
  во временный момент регистрации (файл удаляется после переноса в Secrets).
- `state/*/ok-session.b64` — в `.gitignore`.
- **Репозиторий публичный**: пароль героя в истории git = реальный доступ к аккаунту.
  Правило: креды никогда не коммитятся (`state/*/credentials.json` и `credentials-*.json`
  в `.gitignore`), регистрация отдаёт их артефактом прогона, а не коммитом.
  Если пароль уже утёк — сначала смена пароля в игре, потом чистка истории.
- **BOM в секретах**: значение, записанное через PowerShell-перенаправление, получает
  префикс U+FEFF, и вход в игру падает с «Неверный ник или пароль». Лечится
  перезаписью секрета очищенным значением (проверяй длину ника в логе).
