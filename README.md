# Агент для игры «Варвары» (barbars.ru)

Автономный игрок: сам ходит в бои, тратит очки талантов, чинит снаряжение,
берёт клановые задания, качает клан и героя. Логика — детерминированные правила,
а спорные развилки (какую цель бить, какой талант качать) решает Claude API.

Аккаунт не светится наружу: бот работает в отдельном профиле Playwright, ты логинишься
в него один раз руками (или один раз настраиваешь автовход) — пароль боту в чат не передаётся.

## Быстрый старт (3 шага)

```bash
cd barbars-agent
pip install -r requirements.txt
python -m playwright install chromium
python run.py play
```

`play` сам откроет браузер и попросит войти (если сессии нет). Дальше — работает сам:
бьётся, чинит, качает таланты, берёт задания, вкладывает железо в клан, ждёт
обновления дневных лимитов.

## Что агент умеет

- **Бои.** Заходит в доступные бесплатные бои (башни, подземелья, дуэли), в каждом ходу
  бьёт, когда энергия почти максимальная (удар с «полного» меча сильнее), применяет
  умения по кулдауну: буст урона → щит на низком HP → уворот на критическом HP.
  Пьёт зелья при низком здоровье, отступает при критическом.
- **Починка.** Следит за прочностью: «Починить все вещи за N» (чинит всё сразу).
- **Фарм опыта железом.** Покупает опыт у Мудреца: 10 000 железа → 5% прокачки
  (≈2.85G опыта) — раз в сутки, золотые варианты не трогает.
- **Продажа ресурсов.** Следит за аукционом ресурсов: находит медианную цену
  за единицу по лотам, копит мифрил и бутылочки до порога и выставляет лот
  на 0,05 серебра дешевле рынка. Железо не продаёт никогда. Следит за своими
  лотами и снимает их, если рынок просел. Учитывает аренду лота (5 серебра/24ч)
  и налог 5% — не выставляет лоты, что не окупаются.
- **Колодец удачи.** Забирает бесплатный ежедневный подарок.
- **Авторазбор.** Разбирает обычные вещи в железо (и мифрил с профессией).
- **Алтарь клана.** Каждые 30 минут проверяет бонус алтаря и подновляет его, когда он
  протухает (~2,5 часа): жертвует 1250 железа (+12,5% ко всем параметрам клана).
  Золото на алтарь не тратится никогда.
- **Таланты.** Тратит накопленные очки (приоритет — список в `config.json`,
  при спорных местах советует Claude).
- **Клан.** Берёт клановые задания под текущие активности, может вкладывать
  излишки железа и мифрила в хранилище клана.
- **Экономика.** Золото не тратится никогда: ни на бои, ни на алтарь, ни в магазине.
  Железо расходуется на починку, алтарь и покупку опыта; на аукционе продаются
  только мифрил и бутылочки.

## Установка

```bash
cd barbars-agent
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m playwright install chromium
```

## Первый вход (один раз)

```bash
python run.py login
```

Откроется окно браузера. Войди в игру руками (логин/пароль) — агент в этот момент
ничего не делает, только ждёт авторизацию.

**Важно про сессию:** игровая сессия живёт внутри одного процесса браузера. Поэтому
команда `play`/`once` сама открывает окно и просит войти, если сессии нет:

```bash
python run.py play
# [вход] Сессия не активна: войди в игру в открытом окне браузера.
```

Логин и пароль боту не передаются — он лишь ждёт, пока появится ссылка «Выход».
Поэтому не запускай агента в `--headless` с профилем: после перезапуска браузера
сессия может слететь и понадобится вход заново.

Проверить окружение: `python run.py doctor`.

### Автовход (чтобы вообще не трогать агент)

Игровая сессия живёт внутри процесса браузера, поэтому после перезапуска компьютера
вход нужно повторить. Чтобы этого не делать, создай рядом с `config.json` файл
`credentials.txt` (две строки: ник, пароль):

```
keis
твой_пароль
```

Файл добавлен в `.gitignore`, пароль никуда не отправляется — агент вводит его
сам в форму `https://barbars.ru/login` при старте. Альтернатива — переменные
окружения `BARBARS_USER` и `BARBARS_PASS`.

Альтернатива без файла: `python run.py login` — вход руками, и в том же окне
сразу стартует игра (`run.login_then_play: true`).

### Запуск в фоне с автоперезапуском

```powershell
powershell -ExecutionPolicy Bypass -File .\start_agent.ps1
```

Скрипт крутит `run.py play` и поднимает его заново, если агент упал.

### Чтобы стартовало само при включении компьютера

Диспетчер задач → «Создать задачу» → триггер «При входе в систему» →
программа `powershell.exe`, аргументы:

```
-ExecutionPolicy Bypass -File "C:\Users\Богдан\Documents\Богдан MINIMAX\barbars-agent\start_agent.ps1"
```

Задачу запускать «только когда пользователь вошёл в систему» — иначе окно браузера
не появится в твоей сессии.

## Запуск

```bash
python run.py play              # автономная игра, пока не остановишь (Ctrl+C)
python run.py play --iterations 5   # пять циклов и выход (для теста)
python run.py once              # одно решение + одно действие
python run.py discover          # выгрузить HTML/текст страниц в knowledge/discovered
```

Логи: `logs/agent-ГГГГММДД.log`.

Дневной лимит боёв (2 в подземельях + 3 в дуэлях) исчерпывается за день; когда боёв
не осталось, агент не платит золото (если это не разрешено в конфиге), а засыпает
на `idle_sleep_no_fights_sec` и продолжает с новыми лимитами.

## Проверки

```bash
python tests/test_local.py        # правила, боевая политика, парсер чисел
python tests/test_combat_parse.py  # парсер боевой страницы на реальной разметке
```

## Claude API (необязательно)

Правила работают и без LLM. Чтобы включить советник:

```powershell
$env:ANTHROPIC_API_KEY = "sk-ant-..."
```

LLM вызывается только на неоднозначных развилках и не чаще `llm.max_calls_per_hour`
(по умолчанию 60/час). Модель — `claude-sonnet-4-5`, меняется в `config.json`.

## Настройки (`config.json`)

| Ключ | Смысл |
|---|---|
| `profile_dir` | папка профиля браузера с сессией |
| `headless` | `true` — без окна браузера |
| `spend.allow_gold_fights` | разрешить бои за золото (по умолчанию `false`) |
| `spend.allow_shop` / `allow_auction` | покупки в магазинах/аукционах (по умолчанию `false`) |
| `spend.clan_donate` | вклад железа/мифрила в клан + сколько оставлять себе |
| `targets` | приоритет типов боёв (dungeon, tower, duel, arena, survival, greats, contests) |
| `talent_priority` | порядок прокачки талантов |
| `fight.energy_attack_threshold` | доля от максимума энергии, с которой бьём (0.85) |
| `fight.hp_flee_threshold` | HP в процентах, ниже которого отступаем |
| `fight.use_potions_below_hp` | ниже какого HP пьём зелье |
| `fight.max_turns` | максимум ходов в одном бою |
| `run.idle_sleep_sec` | пауза, когда нет доступных действий |
| `run.idle_sleep_no_fights_sec` | пауза, когда дневные бои исчерпаны (900 с) |
| `humanize.*` | «человечный» темп работы (см. ниже) |
| `altar.enabled` | всегда подновлять бонус алтаря клана |
| `altar.amount` | сколько железа жертвовать в алтарь (1250) |
| `altar.keep_iron` | сколько железа держать в запасе перед жертвованием |
| `altar.allow_money` | если железный вариант недоступен — жертвовать 87 серебра |
| `altar.check_interval_min` | как часто проверять алтарь (30 мин) |
| `altar.renew_before_min` | за сколько минут до протухания подновлять (25) |

## Человечный темп (`humanize`)

Чтобы поведение не выглядело как ровный машинный цикл, агент работает с рандомными
паузами и микродвижениями:

| Ключ | Что делает |
|---|---|
| `enabled` | включить/выключить всё «человечное» |
| `action_delay_min/max` | пауза перед кликом и после него (сек) |
| `page_delay_min/max` | пауза при переходе на страницу |
| `fight_delay_min/max` | пауза между ходами в бою |
| `long_pause_chance` | вероятность «отвлечься» (0.06 ≈ 6% действий) |
| `long_pause_min/max` | длительность такой паузы (9–26 с) |
| `mouse_jitter` | курсор идёт к кнопке по ломаной линии, а не телепортом |
| `scroll_chance` | иногда страница «прокручивается» перед чтением |

Пример «ускорить» (без пауз вообще):

```json
"humanize": { "enabled": false }
```

Честно: паузы делают работу медленнее и маскируют только самый явный признак —
одинаковый ритм кликов. Если у игры есть серверный антибот, он смотрит на свои
признаки, и паузы их не отменяют.

## Безопасность (по умолчанию)

- Никаких покупок, никаких боёв за золото, никаких вкладов золота/серебра.
- Тратится только железо (на починку) и мифрил (в клан).
- Пароль и логин боту не передаются — только сохранённая сессия в профиле браузера.
- Логин-ссылка (выход) агент не трогает.

## Если что-то не работает

1. `python run.py discover` — выгрузка страниц в `knowledge/discovered/`.
2. Посмотри `logs/agent-*.log`: там видно, какое решение принималось и что не нашлось.
3. Селекторы в `barbars/driver.py` сделаны максимально «по-тексту», а не по CSS-классам,
   поэтому правки обычно не нужны. Если игра поменяла формулировки («Починить все вещи»
   → «Починить»), допиши нужные слова в `barbars/driver.py` и `barbars/pages.py`.
